# Password Generator

React ile yapılmış responsive şifre oluşturma uygulaması.

Demo: [Password Generator](https://ismailcubuk.github.io/PasswordGenerator/)

## Özellikler

- Rastgele şifre oluşturur
- Şifre uzunluğu seçilebilir
- Büyük harf, küçük harf, sayı ve sembol seçenekleri vardır
- Şifre gücünü gösterir
- Oluşturulan şifre kopyalanabilir
- Son oluşturulan şifreler görüntülenebilir

## Kurulum

```bash
npm install
npm start
```

Local adres:

```text
http://localhost:3000/PasswordGenerator
```

## Build ve Deploy

```bash
npm run build
npm run deploy
```
